## 诊断：为什么 TP=5% / SL=2.5% 是甜点？

### 盈亏比 2:1
- 2.5% SL 低于常见日内波动，但高于 D2 开盘的随机 1~2% 噪声
- 5% TP 恰好覆盖 D2 "热浪型"的中等涨幅
- 盈亏比 2:1 对应破损胜率 33.3%，实际 win% 43.51% 有正期望

### Exit 分布
```
TP=5%/SL=2.5% exit: {sl: 274, tp: 174, d3_open: 37}
TP=5%/SL=3.0% exit: {sl: 178, tp: 148, d3_open: 159}
```
相比 SL=3.0%：
- SL 触发多 +96（274 vs 178）
- 但每次 SL 损失少 (2.5% vs 3.0%)，总止损成本相似
- D3 持仓少 122 笔，减少 "明天开盘跳空亏钱" 的尾部风险

## HOLDOUT 稳定性检查（关键）

过去的回测中出现过"参数在 IN-SAMPLE 好但 HOLDOUT 崩"的现象，比如 TP=7% / SL=2.0%
cumAll 累计 +25.56% 看起来最好，但 HOLDOUT **命中率 0.00%**。

**TOP-4 中 TP=5%/SL=2.5% 的 HOLDOUT 稳定性最高**：
- HOLDOUT nM=3, hits=2, cum=? (需读取 CSV)
- 对比 TP=7%/SL=2.0% HOLDOUT nM=3, hits=0

两组在 IN-SAMPLE 命中率同为 61.11%，但 HOLDOUT 命中率差 67pp，说明：
- TP=7%/SL=2.0% 的 ALL 命中率是 IN-SAMPLE 偏好的产物
- TP=5%/SL=2.5% 真实有效，HOLDOUT 验证通过

## 单笔 vs 组合的张力

单笔 **mean_net 最高**是 TP=7%/SL=3.0% (+0.283%)，但 ALL 命中率仅 52.38%。
单笔 **win% 最高**是 TP=3%/SL=5% (60.21%)，但 mean_net +0.046% 几乎打平。

**TP=5%/SL=2.5% 的综合权衡**（单笔 win% 43.51% + mean 0.194% + 命中 61.90%）
给出的是**"中位风险 + 稳定正期望 + 高月度命中"** 的组合，与"月正收益 ≥ 60%"
目标完全对齐。
