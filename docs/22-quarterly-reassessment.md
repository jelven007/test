# 季度目标重设计：季度收益 ≥10% 概率 ≥80% 可达吗？

> 实验窗口：2025-01-01 ~ 2026-09-28（7 个日历季度，holdout 仅 1 季）  
> 复用融合管线 L2 (D1≥3%) + L4 (Rule A) + L5 (LHB) + L6 (gap gate) + L1 soft 可选  
> 组合规则：单票 20%，≤5 并发，月度收益按单笔净 × 权重求和，**季度 = 月度连乘**  
> 产物：[research/fusion-mvp/quarterly_report.json](../research/fusion-mvp/quarterly_report.json)、脚本 [scripts/quarterly_reassessment.py](../scripts/quarterly_reassessment.py)

---

## 为什么调整到季度目标？

上一轮 [20-mvp-fusion-backtest.md](20-mvp-fusion-backtest.md) 和 [21-mvp-fusion-with-l1.md](21-mvp-fusion-with-l1.md)
均显示：
- 月≥5% 全区间命中率仅 19.05%（L4+L5+L6），holdout 33.33%
- T+1 持仓的 1 日空间上限限制了单笔均净 ≈ +0.4%
- 月度要稳定 ≥5% 需 ~2% 稳定均净，与数据证据不符

> 自然推测：**延长到季度，用月连乘平滑波动**，是否能让"概率 80%" 变得现实？

## 诊断

### 季度命中天花板约 28.57%（远低于目标 80%）

即使不加任何过滤（L0 baseline），全区间 7 季也只命中 2 季（2025-Q1 +15.63%、2026-Q2 +45.15%）。
两次命中都来自**行情本身**，而非策略。

### 融合规则反而降低了季度命中率

L4+L5+L6 过滤后：
- ALL 命中率 **28.57% → 14.29%**（丢掉了 2025-Q1 的 +15.63% 行情）
- 累计收益反而显著改善：**-38.46% → -15.09%**（减少了尾部大跌）

**融合规则在"降低风险"维度有效，但在"抓住季度 10%+ 行情"维度反而是负贡献。**
核心矛盾：Rule A 本质是"选择 D1 收盘前已回落的样本"——这类样本在
**普涨季度**反而被排除；而普涨季度正是能达到 ≥10% 的季度。

### 具体季度拆解

**L0 baseline 命中季**：
- 2025-Q1：Jan +0.19% × Feb -2.70% × Mar -20.36% = **-21.86%** → 为什么是 +15.63%？

重算发现，L0 baseline 的月度数据与 L4+L5+L6 过滤后的数据使用相同的组合逻辑但样本池不同。
L0 命中的 2025-Q1 (+15.63%) 实际是用 n=~100+ 全样本池按 **5 并发取 top-5** 聚合的结果，
与融合管线的具体月度不是同一组数（见 scripts 中 monthly_pool 函数）。

### holdout 太小无法下结论

Holdout 只剩 2026-Q3 一个完整季度，统计学上无意义。
最早要到 2026-Q4 结束（2026-12-31）才有第 2 个 holdout 季度。

## 季度目标是否可达的理论上限

**从单笔经济学倒推**：
- 融合规则 holdout 单笔均净 +0.43%
- 季度约 60 个交易日 × ~1 单/日（并发 5）× 20% 权重 ≈ 60 单
- 季度期望净 = 60 × 0.43% × 20% ≈ **5.16%** （算术均）
- 实际 holdout 2026-Q3 累计 +4.28%，与倒推一致

**结论：L4+L5+L6 的均净单笔收益不足以稳定做到季度 ≥10%**。要达到 10%，
单笔均净需要翻倍到 ≈ +0.85%，远超当前 edge。

## 判定

| 维度 | 结论 |
| --- | --- |
| 季度≥10% 概率 80% | ❌ **不可达**。实测天花板 28.57%，距离 80% 差 2.8 倍 |
| 融合规则效果 | ✅ 风险减半（累计 -38.46% → -15.09%），但命中数反而少 |
| L1 soft 代理 | 仍非正信号，季度维度全部 0 命中 |
| 升级实盘 | ❌ 不升级。first-board-positive-v1 继续冻结 |
| 根本瓶颈 | **单笔均净 +0.43% 的 edge 本身不够大**，不是时间粒度问题 |

## 建议路线调整

当前 D1≥3% + T+1 开盘买/开盘卖的框架已被充分探索，继续加过滤层只能
**降低风险而非拉升期望**。要让"季度 10% 概率 80%" 变得现实，需要：

1. **放大单笔 edge（最优先）**：
   - 把 Rule A 收紧到更极端 (`r_last30 < -1%` 且 `close_loc < 0.5`)——但样本会从 66 掉到 ~15，统计不显著
   - 用更长持仓窗口（D2 买、D4/D5 卖）捕捉 2 日以上空间——需要重做数据
   - 加入"动态止盈"（Layer 7）：如 D2 盘中 +5% 止盈 / -3% 止损，而非固定 D3 开盘卖
2. **降低目标为"季度正收益 100%"或"季度跑赢沪深 300 概率 80%"**（更现实的目标）
3. **接受"策略做风险管理不做暴利"**：当前融合规则 holdout 累计 +4.28%（优于基线 -50.07%），用来**降低回撤**而非博取 10% 季度收益，是现实的使用方式
