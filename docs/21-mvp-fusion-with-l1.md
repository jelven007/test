# Layer 1 情绪门禁并入融合回测：负面结果与反直觉诊断

> 实验窗口：2025-01-01 ~ 2026-09-28  
> 融合层：L2 (D1≥3%) + L4 (Rule A) + L5 (LHB 反向) + L6 (D2 跳空闸门) + **L1 情绪门禁 (本轮)**  
> 产物：[research/fusion-mvp/report_with_l1.json](../research/fusion-mvp/report_with_l1.json)、脚本 [scripts/mvp_fusion_backtest_with_l1.py](../scripts/mvp_fusion_backtest_with_l1.py)

---

## 实验设计

真实 Layer 1 scorer 当前只覆盖 2026-09-09~09-24 共 12 个交易日，不足以回测 21 个月。
为立即验证"情绪过滤能否提升月度命中率"，构造一个 **lookahead-free 的情绪代理**：

```
每日 proxy_count = 当日 D1 涨幅 ≥ 3% 股票总数（来自 candidates.json.gz）
rolling 20 日分位数 → sentiment_score ∈ [0,100]
四分位切分 → ice (<25) / start (25-50) / ferment (50-75) / climax (≥75)
```

两种过滤模式：
- **Hard**：D1 为 climax 日 → 完全跳过该信号
- **Soft**：按 `position_multiplier` 调整单票仓位（ice 1.5 / start 1.0 / ferment 0.75 / climax 0.0）

## 代理与真实 scorer 校准：**几乎完全不匹配**

| 日期 | 代理状态 | 真实状态 | 代理分 | 真实分 | D1≥3% 计数 |
| --- | --- | --- | --- | --- | --- |
| 2026-09-09 | climax | ferment | 84.21 | 53.01 | 37 |
| 2026-09-10 | ferment | ice | 60.53 | 21.48 | 34 |
| 2026-09-11 | ferment | start | 63.16 | 26.84 | 35 |
| 2026-09-14 | ice | ferment | 0.00 | 50.76 | 29 |
| 2026-09-15 | ferment | ice | 52.63 | 23.90 | 34 |
| 2026-09-16 | ice | **climax** | 23.68 | 86.88 | 31 |
| 2026-09-17 | ferment | start | 65.79 | 41.33 | 35 |
| 2026-09-18 | ice | ferment | 23.68 | 60.19 | 31 |
| 2026-09-21 | start | **climax** | 39.47 | 85.68 | 32 |
| 2026-09-22 | start | **climax** | 42.11 | 79.83 | 33 |
| 2026-09-23 | ice | start | 0.00 | 43.63 | 28 |

**exact match 0/11, within±1 bin 4/11**。两个指标正交：
- 真实情绪高潮 (09-16/09-21/09-22) 的核心特征是**涨停数爆发到 89~103**；
- 这些日 D1≥3% 的"宽基"计数只有 31~33，相对窗口反而是"冷清"；
- D1≥3% 计数更多反映"参与广度"而非"情绪强度"。

**结论：D1≥3% 计数不能作为真实情绪的代理**。本次 L1 测试结果只在"宽基广度"维度有意义，不能当作对真实 Layer 1 效果的证据。

### 为什么单笔略好但月度崩了？

关键观察 holdout 2026-07：
- `no-L1`：n=29, 月收益 **+5.06%** → 刚好命中目标
- `L1 hard`：n=23（跳过 6 单），月收益 **+1.48%** → 失去命中

被 L1 hard 剔除的 6 单恰好是该月涨幅排名前 5 的"热浪型"信号。D1≥3% 计数代理把这些高胜率日判定为 climax 后，正是把牛市最赚钱的样本扔掉。

### 唯一正面迹象：L1 soft 在 holdout 累计收益最高 (+7.06%)

Soft 模式按仓位乘数降权没有完全丢弃信号，holdout 累计收益从 +4.28% 提升到 **+7.06%**，仅 3 个月样本不显著但方向对——它在高潮月减仓、冰点月加仓，净效果好于完全跳过。

## 判定

| 维度 | 结论 |
| --- | --- |
| 代理有效性 | ❌ D1≥3% 计数 ≠ 真实情绪，0/11 完全不匹配 |
| L1 hard 整体 | ❌ 命中率从 19% 掉到 10%，holdout 命中归零 |
| L1 soft 单项 | ⚠️ holdout 累计 +7.06% 优于 no-L1 +4.28%，但命中率仍 0% |
| 目标 月≥5% 概率 80% | ❌ 未达成，所有模式都远低于目标 |
| 升级实盘 | ❌ 不升级。模拟盘 first-board-positive-v1 继续冻结 |

## 下一步建议

1. **等真实 Layer 1 累积 ≥60 个交易日**（预计 2026-12 底）再做"真·L1 并入"回测，别用宽基广度代理顶替。
2. 短期可改进代理：改用 **daily 涨停总数**（`akshare stock_zt_pool_em`，但只有近 20 日）或 **指数当日最高涨停连板高度**（本地可计算，但需要全市场分钟数据），估计与真实 scorer 相关性更高。
3. 组合层面诊断：当前月度崩溃主要来自 2~3 个尾部大跌月，而非"情绪高潮"识别本身——下一步可能更应该做 **月度止损 / 动态仓位** (Layer 7) 而非情绪门禁。
4. 承认 **1 日 T+1 持仓的空间上限**：Rule A 已经把 holdout 单笔均净推到 +0.4%，但组合要达到月≥5%×80% 需要 ~2% 稳定均净，不切实际。
