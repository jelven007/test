# Web UI 标准

## 1. 范围

共享标准覆盖 FastAPI 提供的四个业务页面：

| 路径 | 页面 |
| --- | --- |
| `/strategy` | 策略管理 |
| `/` | 次日计划 |
| `/monitor` | 盘中监控 |
| `/research` | 回测优化 |

基础页面样式保留在各自 CSS 中，跨页面令牌和组件规范统一由
`src/banxia_strategy/web/ui-standard.css` 管理。四个 HTML 页面必须使用相同版本的
`/ui-standard.css` 查询参数，避免浏览器缓存混用。

## 2. 设计令牌

- 页面底色、正文、弱化文字、边框及成功/风险/警告/信息色统一使用 `:root` 变量。
- 正文字体使用系统中文无衬线字体；代码、时间、版本号和数据源使用等宽字体。
- 默认控件高度 `40px`，圆角 `4px`，内容最大宽度 `1440px`。
- 页面字号不随视口宽度缩放，字距固定为 `0`。
- 页面禁止产生横向溢出；只有表格容器允许独立横向滚动。

## 3. 共享组件

| 组件 | 标准类或结构 | 约束 |
| --- | --- | --- |
| 顶栏 | `.topbar` / `.monitor-header` | 固定顶部、统一边框与背景 |
| 主导航 | `.primary-nav` | 固定顺序，当前页使用 `aria-current="page"` |
| 主内容 | `.page-main` | 统一最大宽度和响应式页边距 |
| 页面标题 | `.page-header` | 标题、说明和操作区不相互挤压 |
| 输入控件 | `.ui-control` | 统一高度、边框、聚焦环和禁用状态 |
| 命令按钮 | `.ui-button` | 主按钮、危险按钮和普通按钮使用明确状态 |
| 状态标签 | `.status-badge` | 状态色只表达语义，不作为唯一信息来源 |
| 页面状态 | `.ui-status` | 加载、成功和错误反馈占用稳定高度，错误使用 `.is-error` |
| 分段切换 | `.segmented-control` | 使用 `aria-pressed` 表达当前选项 |
| 数据表格 | `.data-table` | 统一表头、行高、悬停、选中和空状态 |
| 表格容器 | `.table-scroll` 等 | 可聚焦、带区域名称，仅容器允许横向滚动 |
| 链接 | `.ui-link` 等 | 统一颜色、下划线和悬停状态 |
| 对话框 | 原生 `dialog` | 保留键盘焦点与关闭路径 |

所有交互控件必须具有可见的 `:focus-visible` 状态。状态、加载、空数据和错误文案不得通过
颜色单独传达。

## 4. 响应式要求

- 桌面端按受约束内容区展示，不使用装饰性嵌套卡片。
- `800px` 以下，页面标题和操作区改为纵向布局，所有数据表格在自身容器内滚动，
  不将表格转换成另一套卡片结构。
- `560px` 以下，策略和研究页顶栏改为单列，隐藏次要来源标签；策略字段为单列，
  操作按钮使用两列网格，主保存按钮占整行。
- `480px` 以下，次日计划顶部的策略选择器独占一行，日期与刷新按钮保持稳定宽度。
- 验收视口至少包含桌面端和 `390x844` 移动端；页面级横向溢出为失败。

## 5. 业务一致性

- 四页主导航顺序固定为“策略管理、次日计划、盘中监控、回测优化”。
- 策略选择、交易日选择、刷新、激活、删除和下载等命令沿用相同控件语义。
- 策略管理默认使用可横向滚动的数据表展示关键参数；策略名称是进入详情的主链接。
- 详情页名称保存是独立操作；参数变化必须使用“保存为新策略”并弹出名称输入对话框。
- 研究候选必须明确显示“未激活”；实时页面必须显示行情时间和数据状态。
- 次日计划刷新按钮触发完整报告任务，生成期间禁用，成功后重新载入报告。
- UI 不提供自动下单、账户、持仓或券商操作入口。

## 6. 自动化校验

`tests/test_infrastructure_layout.py` 检查：

- 四页加载同一版本的共享样式。
- 四页存在统一主导航和 `.page-main`。
- 共享控件、表格、状态、链接和响应式规则存在。
- 状态反馈保留共享 `.ui-status` 类，错误态使用 `.is-error`。
- 策略、监控和研究表格容器可通过键盘聚焦，并提供可访问名称。
- CSS 不使用负字距。
- 次日计划刷新调用 `/api/v1/reports/{tradeDate}/refresh`，按钮文案为“刷新”。

视觉变更还需在桌面和 `390x844` 视口进行浏览器截图检查，确认无重叠、截断和页面级横向滚动。
