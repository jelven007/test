# 涨停档案

## 已实现

- `/limit-ups`：沪深主板、创业板、科创板收盘涨停档案，默认从 2025-01-01 查询。
- PostgreSQL `banxia.limit_up_history` 保存逐日事实，`limit_up_history_coverage` 保存包括零样本日期在内的交易日采集覆盖；`limit_up_history_sync` 保存每次任务及失败证券。
- `GET /api/v1/limit-up-history` 支持日期、代码/名称、板块、行业，以及总市值、流通市值、换手率、振幅、开盘涨幅、当天涨幅、5 日涨幅的上下限组合筛选、排序和分页。金额 API 单位为元，页面输入单位为亿元，百分比单位为百分点。
- `GET /api/v1/limit-up-history/options` 返回行业、日期覆盖和最近同步状态。
- 页面新增「月度涨停趋势」与「个股涨停次数」，与全部筛选条件同步。曲线可切换涨停次数和月内去重股票数，悬停、触摸或键盘聚焦数据点可查看数值与采集覆盖。个股按次数降序（同次数按代码升序）分页，点击名称可筛选该股的曲线与明细。
- 查询传 `include_statistics=true` 时返回 `monthly_counts` 和 `stock_counts`。统计针对全部匹配事实，不受明细 `limit/offset` 影响；个股分页使用独立的 `stock_limit`（1–100，默认 10）和 `stock_offset`。默认不查询聚合，兼容原有调用。
- `banxia-service limit-up-history-sync` 首次回填全量；后续从成功同步日期回看 14 个自然日。VKE CronJob 每个工作日北京时间 16:35 执行，已有完整回填时跳过非交易日。

## 计算与数据边界

唯一外部数据来源是 mootdx：日 K、财务股本、除权除息/股本变动记录及 F10 公司概况。

| 指标 | 口径 |
| --- | --- |
| 总市值 | 当日不复权收盘价 × 当日总股本 |
| 流通市值 | 当日不复权收盘价 × 当日流通股本 |
| 换手率 | 成交量（手）× 100 ÷ 流通股本 × 100% |
| 振幅 | （最高价 − 最低价）÷ 参考昨收 × 100% |
| 开盘涨幅 | （开盘价 ÷ 参考昨收 − 1）× 100% |
| 当天涨幅 | （收盘价 ÷ 参考昨收 − 1）× 100% |
| 5 日涨幅 | （本日收盘价 ÷ 前第 5 个有行情交易日收盘价 − 1）× 100%，不复权 |
| 行业 | 当前 F10「行业类别」第一层分类；全文保存在 raw.industry_full |
| 月度涨停次数 | 当月符合筛选的股票 × 交易日记录数；同一股票不同交易日分别计次 |
| 月度去重股票数 | 当月符合筛选的不同证券数；一只股票当月多次涨停只计 1 只 |
| 个股涨停次数 | 筛选日期内该证券符合所有条件的涨停记录数；仅列至少有 1 条的股票 |

月度图仅展示已采集日期覆盖范围，首尾月份按查询日期截取。有采集覆盖但无匹配记录的月份显示 0，范围内完全缺失的月份返回空值并断开曲线，未采集的末尾月份不虚构为零。部分完成的月份在数据点说明中标记待补齐交易日数。以上统计默认排除 5% 待核实候选，勾选开关时一并计入。

历史股本优先读取下一次股本变动的变动前股本，或最近一次变动后的股本（源单位万股）。没有有效历史股本记录时，使用当前财务快照并在明细中标注「股本估算」。股本日期和计算依据均入库；无法取得的指标保持空值，参与数值筛选时不匹配。

除权日根据 mootdx 分红、配股、送转记录重建并四舍五入到分的参考昨收。源分类 11/12 的缩扩股事件因参考价信息不足跳过。5 日涨幅保持不复权，因此除权窗口的累计涨幅不代表含分红总回报。

收盘价须严格等于四舍五入后的涨停价；超过涨停价不计入。2023 年注册制后新股上市前五个行情交易日排除。创业板、科创板按 20% 价格档，主板按 10% 价格档识别。

**mootdx 不提供可追溯的历史 ST 状态。** 命中主板 5% 价格档的记录仅作为「5% 待核实候选」保存，默认查询排除；勾选页面开关或传 `include_unverified=true` 才返回。这些候选可能包含普通上涨股票，不可直接视为已确认 ST 涨停。

范围是同步时 mootdx 可见的沪深 A 股名单，历史名称及行业为当前资料，可能缺少已退市股票。源数据本身缺口和特殊复牌无限价日无法仅靠日 K 完整核验，档案不等同于交易所官方历史涨停名单。

## 同步保证

- 指数日 K 决定实际交易日期；盘中不保存当日未收盘数据，节假日不制造样本。
- 日 K 分页回溯，至少保留范围前五个交易日；每个工作线程复用连接，失败切换节点重试。
- 仅当日 K 为空、财务上市日期/总股本/流通股本明确为 0，且 F10 上市日期明确为 `-` 时，作为未上市证券排除。代码、原因和依据保存在同步任务的 `excluded_symbols`；有效证券总数不含这部分。其他空行情仍算失败并重试。
- 逐股计算并释放日 K，避免全市场历史常驻内存。
- PostgreSQL advisory lock 阻止同时回填。成功证券在事务中删除本次范围旧事实后重建，可以纠正误判和已消失的样本；失败证券原记录保留。
- 部分失败写入 `partial`，不推进成功水位，Job 返回失败以便调度重试。初次完整回填成功前不会根据最新样本日期跳过早期历史。
- 股票主数据快照由独立任务管理；档案保存稳定 `exchange:stock:symbol` 标识，不依赖主数据任务先于历史采集完成。
