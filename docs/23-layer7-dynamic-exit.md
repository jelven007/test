## 实现

每笔 D2 分钟遍历：
```
buy = D2 minutes[0]
for i in 1..239:
  if min(prev,cur) <= buy*(1-SL): exit at buy*(1-SL), reason='sl'
  elif max(prev,cur) >= buy*(1+TP): exit at buy*(1+TP), reason='tp'
otherwise: exit at D3 open, reason='d3_open'
```
SL 与 TP 同一分钟同时触发时保守假设 SL 先成交。
> 数据限制：TDX 分钟缓存只有 close，用 min(prev,cur) 和 max(prev,cur) 作为 low/high 近似。
> 真实 tick 填单会偏乐观（跳空和插针无法完整复现），但同一代码库下不同 (TP, SL) 组合**相对可比**。

1. **mean_net 从 -0.09% 显著提升到 +0.21% ~ +0.28%**（TP 5~7 / SL 3~5）。单笔 edge 翻倍。

## 为什么单笔 edge 翻倍却反而命中率归零？

诊断 holdout 2026-07（原 baseline 命中月 +5.06%）：

- Baseline 下该月盈利月的驱动是 "少数几只热浪股单日 10%+"
- L7 TP=7% 配置将这些单笔截断在 +7%（扣费 +6.7%），大赢家失去 "尾巴"
- 同时, TP=5% / SL=3% 虽然均净 +0.21%, 但分布更均匀, 月度**没有偏斜**
- 月度 20% 单票仓位 × 5 并发 = 单月权重 100%, 单月要 ≥5% 需至少 1~2 只个股贡献 25%+ 收益
- Baseline 保留"大赢家长尾"刚好能偶尔命中, L7 把分布正态化后再也命中不到

**用图景说明**：
```
baseline 单笔分布: [许多 -2%, 少数 -10%, 偶尔 +15%]  → 月度偏斜大, 偶尔命中
L7 (TP=7/SL=3) 分布: [许多 -3% 止损, 许多 +6.7% 止盈]  → 月度分布正态, 命中率归零
```

**L7 的"降低风险"效果显著但"降低峰值"更显著**——这是组合层面不想要的方向。

## 根本结论

**本框架内所有"月度≥5% 概率≥80%" 和 "季度≥10% 概率≥80%" 的目标都不可达**：

1. [20-mvp-fusion-backtest.md](20-mvp-fusion-backtest.md)：L4+L5+L6 月命中率 19.05%（ALL） / 33.33%（HOLDOUT 3 月）
2. [21-mvp-fusion-with-l1.md](21-mvp-fusion-with-l1.md)：L1 情绪代理拉低到 9.52%
3. [22-quarterly-reassessment.md](22-quarterly-reassessment.md)：季度口径天花板 28.57%
4. **本轮**：L7 动态止盈把月命中率拉到 ≤14.29%，holdout 归零

**根本矛盾**：
- 月≥5% 需要长尾月份爆击 → 自然方差大
- 单笔 edge 当前上限 ≈ +0.3%（已是 Layer 2+4+5+6+7 最优），对应期望月度 ≈ 3.6%
- 要稳定 ≥5% × 80%，期望月度需要 ≈ 10%+，这意味单笔 edge ≈ +0.8%，超过 D1≥3% + T+1 持仓的物理上限

## 建议路线

### 短期（1 周内）
放弃"月≥5% 概率 80%"和"季度≥10% 概率 80%"目标，接受现实：
- 融合规则是**风险管理工具**（holdout 累计 +4.28% vs 基线 -50.07%，这是真实价值）
- 当前目标应改为 **"月度正收益概率 ≥ 60%"** 或 **"跑赢沪深 300 概率 ≥ 70%"**

### 中期（1 月内）
扩大持仓窗口到 D4/D5（放弃严格 T+1），从数据侧探索更长空间的 edge：
- 需要重新建 `research/*-t5/` 数据集
- 测试 D2 买 + 分批 D3/D4/D5 卖的分段退出
